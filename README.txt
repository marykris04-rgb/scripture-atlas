SCRIPTURE ATLAS v4.0 - HAMBURGER MENU EDITION

HOW TO RUN
1. Keep every file in this folder together.
2. Open index.html in a browser.
3. Upload these files to GitHub Pages or another static host when ready.

UPDATED UI
- Hamburger menu replaces the horizontal navigation bar.
- All navigation pages are inside a scrollable side drawer.
- Theme and Export are grouped under Settings.
- The drawer closes via its close button, backdrop, Escape key, or page selection.
- The shared modal used by profiles and other detail views now has a sticky header and its own responsive scrolling region.
- Mobile modals use a bottom-sheet layout and account for phone safe areas.
- Background page scrolling is locked while a drawer or modal is open.
- Long references, trees, tables, and modal content remain scrollable without overflowing the screen.
- Existing application data and functionality are retained.

LATEST REFINEMENTS
- Removed the duplicate Close profile button from modal content. The persistent X button remains.
- Constrained all filter and category dropdowns to the phone viewport.
- Added offline illustrative artwork to every Character Encyclopedia card and character-profile modal.
- Artwork is selected by the character's recorded role and remains bundled locally.

CUTE AVATARS AND READING STREAK
- Each character now receives a deterministic, name-specific animated avatar with initials, colors, and a role-themed emblem.
- Avatars are generated locally by the app and require no internet connection.
- Opening a character profile records that local calendar day as a reading day.
- The Overview page shows the current streak, longest streak, total reading days, and the current month calendar.
- Reading history is retained in browser localStorage on that device and browser.

- Character artwork refined into full-body cartoon Bible-character illustrations with robes, sandals, expressive faces, hand gestures, and role-based props.

FINAL CARTOON ILLUSTRATION UPDATE
- Replaced generated SVG/initial avatars with locally bundled cute cartoon Bible illustrations.
- Added eight reusable storybook scenes for ark, Exodus, shepherd/king, queen, lions, harvest, fishing, and missionary themes.
- Character cards and profile modals select an appropriate illustration by character name and role.
- Images work offline and remain responsive on mobile screens.

V5.3 DASHBOARD UPDATE
- Recreated the Overview dashboard shown in the supplied reference: large storybook hero, four statistic cards, reading streak calendar, recently read panel, and Psalm 119:105 strip.
- Character encyclopedia images remain enabled. Event encyclopedia and event detail views remain text-only.

V5.5 MOBILE UI UPDATE
- Converted encyclopedia filters into horizontally scrollable pill controls on phones.
- Added a touch-friendly horizontal carousel for Character Encyclopedia cards.
- Added fixed mobile bottom navigation for Home, Characters, Bible, Quiz, and More.
- Restored and retained the full Overview dashboard with the right-side storybook image.
- Event Encyclopedia remains text-only.

V5.7 JOURNAL UPDATE
- Added Daily Devotion with rotating offline reflections and prayers.
- Added My Notes with local browser storage.
- Added Prayer Journal with Active, Answered, and Archived statuses.
- Added Save Devotion to Notes and Save Prayer to Journal actions.
- Retains mobile bottom navigation, full-image Overview dashboard, character images, and text-only Event Encyclopedia.

V5.8 MOBILE LAYOUT FIXES
- Made the side menu independently scrollable through the full mobile viewport.
- Added bottom safe-area spacing so Statistics and Settings remain reachable.
